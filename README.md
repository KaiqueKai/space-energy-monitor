## Descrição do Projeto

O Space Energy Monitor é um sistema desenvolvido em Python para monitoramento de dados simulados de uma missão espacial experimental.

O objetivo do projeto é acompanhar condições operacionais da missão, analisando informações relacionadas à temperatura, energia, comunicação e status dos módulos da estação espacial.

Além do monitoramento, o sistema é capaz de gerar alertas automáticos e executar respostas automatizadas diante de situações críticas, contribuindo para a segurança e eficiência da operação.

O projeto foi desenvolvido com foco em energias renováveis e sustentabilidade, simulando a geração de energia solar e apresentando relatórios de eficiência energética.

## Funcionalidades

* Monitoramento de temperatura da missão.
* Monitoramento do nível de energia.
* Monitoramento da comunicação da estação.
* Monitoramento do módulo habitacional.
* Geração automática de alertas.
* Tomada de decisão automatizada.
* Relatório de sustentabilidade.
* Simulação de geração de energia solar.
* Interface em menu interativo.

## Como Executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `space_energy_monitor.py`.
3. Execute o programa utilizando Python 3.

Exemplo:

python space_energy_monitor.py

## Estrutura do Sistema

O sistema simula uma missão espacial sustentável utilizando dados gerados automaticamente.

Os dados monitorados incluem:

* Temperatura
* Energia
* Comunicação
* Habitação
* Produção de energia solar
* Consumo energético

Quando situações críticas são identificadas, o sistema gera alertas e executa ações automáticas para reduzir riscos operacionais.
